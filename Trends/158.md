---

Qwen3.8 Max가 도구 사용, 계획 수립, 자율성, 다단계 문제 해결 능력을 측정하는 Artificial Analysis Agentic Index에서 Fable 5(57점)를 넘고 GPT-5.6(58점)와 동점을 기록하며 Claude Opus 5(59점)와 1점 차이로 공동 2등에 올랐습니다. 

참고로 Qwen3.8 Max가 Agentic Index에서 Claude Opus 5를 넘어 1위였다가, 벤치마크 업데이트를 거치며 2위로 내려간 것입니다. 사실상 에이전틱 능력 1위로 봐도 문제없을 것 같습니다. 

GLM-5.2 이후로 중국 모델을 OpenAI, 앤트로픽 모델 대신 사용해도 무방할 수준으로 유용해졌고, Kimi K3와 Qwen3.8은 프론티어 모델 수준의 성능을 보이고 있습니다. 

DeepSeek V4 Flash 공식 버전은 크기 대비 최고의 효율을 보여주고, Qwen3.6 27B는 일반 사용자들이 쓸 수 있는 최고의 모델이라며 효용성을 인정받고 있죠.

곧 Qwen3.8 Max와 27B 모델을 오픈웨이트로 공개한다고 합니다. DeepSeek V4 Pro 공식 버전도 곧 공개될 것 같네요. 거기다 바이트댄스는 10T 규모의 모델을 학습 중이라고 하고, MiniMax도 2.7T급 모델을 만들고 있다고 합니다. 

다만 Kimi K3처럼 Qwen3.8 Max도 라이선스 문제가 있을 가능성이 높다고 합니다. 딥시크 모델들의 API 가격도 오를 가능성이 높다고 하네요. 이제 중국 기업들도 본격적인 수익화 작업에 들어가나 싶습니다. 

Kimi K3 사용 시, 최대 30% 수익 배분을 요구한다는 뉴스를 봤습니다. 이번에 Moonshot AI가 Kimi K3 사용으로 여러 파트너십을 맺었는데, 돈을 많이 벌고 있을 것 같네요. 어쩌면 API 판매보다도 더 수익성이 높지 않을까 싶습니다.

당연히 아무것도 공개하지 않은 앤트로픽보다는 훨씬 낫지만, 점점 오픈소스와는 멀어지는 것 같습니다. 이제 중국이 앞선다는 생각이 드니, 슬슬 문을 닫기 시작하는 건가 싶기도 하네요.

이번 독파모는 중국 모델들의 발전으로 저번보다도 주목을 받지 못했습니다. 다시 말하지만, 독파모 평가에서 라이선스를 크게 반영해야 한다고 생각합니다. 현재 우리의 경쟁력이 무엇인지, 지금 시점에서 할 수 있는 최선의 역할이 무엇인지 객관적으로 보면 좋겠습니다.

아무튼 이제 중국이 미국을 잡았습니다. 요즘 실용적이라는 느낌의 논문들을 보면 저자들이 다 중국인입니다. 우리 분야에서 중국의 수준은 매우 높고, 부족한 GPU로도 프론티어 모델까지 미국을 잡았네요. 

중국이 개방하고 미국이 폐쇄적인 기묘한 분야입니다. 미국도 다시 자신들의 장점이 무엇이었나 진지하게 고민해보면 좋겠습니다.
