# SFT와 RL의 관계: 지식을 엮는 것과 부품화하는 것 (ICML 2026)

강화학습(RL)은 새로운 지식을 무에서 유로 창조하는 마법이 아닙니다. RL은 SFT가 어지럽게 쌓아둔 지식을 잘게 쪼개 정리정돈하고 모듈화하는 가공업자에 가깝습니다.

"SFT는 필요 없고, RL만 무한히 돌리면 AI가 스스로 생각을 깨우쳐서 천재가 되는 것 아닌가?", "SFT와 RL 중에서 무엇을 하면 좋을까?" Post-training 열풍 속에서 요즘 많은 분이 던지는 질문입니다. 

ICML 2026에 게재된 카네기 멜론, MBZUAI, 미시간 대학교 연구진의 논문 "From Reasoning Traces to Reusable Modules: Understanding Compositional Generalization in Language Model Reasoning"는 우리가 알고 있던 여러 오해를 바로잡아 줍니다.

1. 원재료 공급자 SFT vs 부품 가공업자 RL

기존의 SFT(Supervised Fine-Tuning)는 사람이나 거대 AI가 적어놓은 정답 풀이 과정을 통째로 암기하는 단계입니다.

 - 얽혀있는 지식: SFT만 거친 AI는 A 스킬, B 스킬, C 스킬을 다 갖추고 있지만, 이들이 문제와 단단히 얽혀(Entangled) 뭉텅이 형태로 뇌리에 적재됩니다.

 - OOD(보지 못한 문제)에서의 무너짐: 그래서 조금만 형태가 바뀐 처음 보는 문제를 만나면 얽힌 지식을 풀어내지 못해 허둥댑니다.

반면 RL은 명확한 보상(Reward Signal)을 바탕으로 수많은 무작위 시도(Rollout)를 돌립니다.

 - 정리정돈과 모듈화: 이 과정에서 AI는 "아, 이 상황에서는 A 스킬만 떼어내서 써야 하는구나!", "B와 C는 이렇게 연결되는구나!"를 깨닫습니다.

 - 재사용 가능한 부품: 통째로 뭉쳐있던 지식을 독립적인 레고 블록(Reusable Modules)으로 잘게 쪼개어 정리(Decomposition)하는 것입니다.

2. SFT 없이 바로 RL만 돌리면 일어나는 비극 (0%의 늪)

그렇다면 SFT 과정을 아예 건너뛰고 Base 모델에 곧바로 RL만 돌리면 어떻게 될까요?

 - 탐색의 불가능 (Rollout Reachability): Base 모델은 문제에 맞춰 다단계로 생각(CoT)하거나 정답 포맷을 맞추는 법을 전혀 모릅니다. 무작위로 아무 말이나 내뱉는데, 이 중에서 정답에 도달할 확률은 0%에 가깝습니다.

 - 보상의 소멸: 정답을 한 번이라도 맞혀야 보상(Reward=1)을 주고 학습을 시키는데, 성공하는 시도가 단 하나도 없으니 학습 그라디언트가 0이 되어 모델이 완전히 멈춰버립니다 (Collapse).

즉, SFT는 RL이 탐색을 시작할 수 있게 만들어주는 최소한의 사전 부품이자 출력 규칙을 제공하는 절대적 필수 전제 조건입니다.

3. SFT와 RL의 문제는 겹치지 않아야 한다

이 논문이 밝혀낸 가장 흥미로운 내용은 데이터의 중복(Overlap)에 관한 법칙입니다.

SFT와 RL 데이터를 다룰 때, 두 데이터셋이 같은 도메인에 속하고 구체적인 문제 조합(Prompt/Instance)은 서로 단 하나도 겹치지 않는 완전한 남남(Disjoint Sets)이어야 일반화 성능이 극대화됩니다. 즉 같은 데이터셋에서도 SFT용 데이터와 RL용 데이터를 나눠야 된다는 의미입니다.

 - 문제 중복의 함정: SFT 때 풀었던 똑같은 문제를 RL에서도 보상(Reward)을 주며 반복 학습시키면, AI는 지식을 모듈화(부품화)하려 노력하는 대신 과거에 외운 답안 패턴을 그대로 우려먹는 꼼수를 택합니다. 이는 이미 배운 문제를 복습하는 데는 도움이 될지 몰라도, 새로운 과제를 풀어내는 지능을 심각하게 망가뜨립니다.

 - Off-support 타겟팅의 마법: 정석적인 방법은 SFT 단계에서 문제 해결에 필요한 원자적 기초 스킬(Atomic Skills)들을 다양하게 넣어주어 부품 상자를 완성하고, RL 단계에서는 SFT에서 한 번도 보여주지 않은 새로운 문제 조합만 선별하여 보상 기반으로 탐색하게 만드는 것입니다.

이 조건(기초 부품 완전 커버 + 문제 조합 완벽 분리)이 갖춰졌을 때, 한 번도 보지 못한 조합의 신규 문제(OOD) 정답률은 SFT 단독 모델 대비 무려 66%p 이상 상승(18.1% -> 84.3%)했습니다.

반면 SFT에서 푼 문제 조합을 RL에서 그대로 중복시키거나, SFT를 거치지 않아 기초 부품 자체가 누락되었을 때는 이 상승폭이 사실상 사라졌습니다.

4. 이미 완성된 Qwen3-4B 같은 Instruct 모델에 바로 RL을 돌려도 될까?

"그럼 이미 잘 완성되어 출시된 Qwen3-4B-Instruct 같은 모델에는 바로 RL을 돌려도 되나요?"

네, 당연히 됩니다! 실제로 수많은 연구와 산업 현장에서 사용하는 표준 접근법입니다.

이미 완성된 Instruct 모델은 사전 SFT를 통해 추론 양식과 수많은 기초 부품(Atomic Skills)을 이미 뇌리에 탑재하고 있기 때문입니다. 탐색 도달 가능성(Reachability)이 확보되어 있으니, 곧바로 RL을 돌려 얽혀있는 지식을 부품화하고 OOD 추론 성능을 극대화할 수 있습니다.

단, 한 가지 주의점이 있습니다. 만약 여러분이 만들고자 하는 특수한 도메인(예: 특수 터미널 명령어 제어, 암호학 도메인 등)의 기초 부품이 해당 오픈 모델의 SFT 단계에 아예 빠져 있었다면, RL을 아무리 돌려도 성능이 오르지 않습니다. 이때는 해당 부품을 채워주는 타겟 SFT를 먼저 진행한 뒤 RL로 넘어가는 것이 정석입니다.


마치며

지식을 넣는 SFT와 일반화를 하는 RL의 조합은 필수적입니다. 이미 유명한 사실을 해당 논문을 통해서 제대로 정리할 수 있었습니다. 

다만 논문은 합성 문자열 변환(Synthetic String Transformation) 태스크로 간단한 실험을 진행한 것이라서 훨씬 더 복잡한 실제 상황에서는 다를 수도 있습니다. 

그리고 4B 모델로만 실험을 한 것이라서, 거대한 모델에서는 어떻게 작동할지 확신할 수 없습니다.
