---

기존 GRPO 강화학습 시 그룹에서 모두 틀리는 어려운 문제의 경우 학습을 포기했습니다. 그런데 이미 아는 문제를 학습시킬 자원을, 어려운 문제를 푸는 데 더 집중해서 학습 시키면 어떨까요? 쉬운 문제는 실력이 비약적으로 늘지만 정작 어려운 문제는 계속해서 풀지 못하는 기존 강화학습의 고질적인 한계를 해결할 수 있을까요?

Mila, 워싱턴 대학교, Allen AI(Ai2) 연구진이 발표한 논문 "Learning to Solve Hard Problems in RL for LLMs by Never Giving Up"은 비동기 스케줄링 수정만으로 어려운 문제의 해결력을 뚫어낸 결과를 보여줍니다.

1. LLM 강화학습의 마태 효과 (부익부 빈익빈)

연구진은 이미 강화학습을 끝낸 세 가지 오픈소스 모델의 도메인별 성능 향상 폭을 분석했습니다.

- 수학(Olmo 3.1 Math on AIME): 쉬운 문제 정답률 +63%p vs 어려운 문제 +3%p
- 코드(DeepCoder on LCBv5): 쉬운 문제 +19%p vs 초고난도 문제 +5%p
- 에이전트 코딩(DeepSWE on SWE-bench): 15분 내 해결 과제 +18%p vs 4시간 이상 난제 +0%p

기존에 강화학습을 잘 끝낸 모델들이, 실력이 골고루 느는 게 아니라 이미 잘하던 쉬운 문제만 기형적으로 더 잘 풀고, 정작 못 풀던 어려운 문제는 여전히 못 푸는 모습이 선명하게 나타났습니다.

2. 포기하지 않는 단순한 루프 (Never Give Up)

연구진은 가치 모델(Critic)이나 복잡한 손실 함수를 추가하지 않고, 비동기 롤아웃 큐의 재시도 규칙(NGU)만 도입했습니다.

- 빠른 손절(K=4): 일단 4개만 뽑아보고 모두 맞히면 즉시 버립니다. K를 늘리면(예: K=32) 쉬운 문제에서 사소한 오답이 섞여 나와 다 푼 문제가 배치를 독점하므로, 작은 K로 쉬운 문제를 빠르게 털어내 연산 낭비를 막습니다.
- 정답 나올 때까지 재도전: 4개 모두 틀리면 버리는 대신, 95% 확률(p=0.95)로 큐에 다시 넣어 추가 시도를 이어갑니다.
- 0.95 난수의 의도: 무조건 끝까지 시도(p=1.0)하면 답이 아예 없는 문제에 갇혀 학습 파이프라인이 정체됩니다(Extra Hard 87.9% 수준에서 p=1.0 적용 시 2.7%로 폭락). 반면 5%의 탈락 확률을 두면 가망 없는 문제는 빠르게 털어내고, 일부 문제에는 100회 이상의 깊은 탐색 기회가 확률적으로 열려 돌파구를 찾아냅니다.

3. 수십 번의 실패 끝에 얻은 정답에 폭탄 보상 (Anchor Positives)

수십 번 틀리다가 극적으로 정답 1개를 건져 올렸을 때, 기존 GRPO 방식으로 계산하면 정답의 상대적 보상(Advantage)이 1 - (1/4) = 0.75 수준에 그칩니다.

NGU는 이전 시도에서 쌓인 오답들을 버퍼에 모아 정답과 함께 하나의 거대한 그룹으로 묶어버립니다. 31개 오답과 1개 정답이 묶이면 정답의 Advantage는 1 - (1/32) = 0.97까지 치솟아 강력한 학습 신호가 됩니다.

여기서 비동기 파이프라인의 오프폴리시(정책 시차) 문제를 막기 위해 두 가지 장치를 둡니다.

- 4스텝 이내 데이터만 역전파: 너무 과거 가중치로 생성된 오래된 오답은 버리고 최근 4스텝 이내의 완성본만 업데이트에 사용합니다.
- 정답 보상 보존(Anchoring): 제외된 오답의 보상 수치까지 전체 평균 계산에는 반영하되, 그룹 합이 0이 되도록 남은 오답들의 감점을 비례 조정하여 정답에 꽂힌 강력한 보상이 희석되지 않도록 묶어둡니다.

4. 검증된 성능: 수학과 복잡한 코딩

- 대규모 수학(Qwen 3 4B on DeepScaler 10k): 동일한 계산량(120 H100 시간) 매칭 하에 AIME 2025와 BRUMO 2025 평가에서 기존 SOTA(Darling, 25.9%)를 넘는 26.5%를 기록했습니다. 특히 초기 모델이 전혀 풀지 못하던 Hard 구간(pass@64=0)에서 일반 GRPO가 +1.6~2.5%p 오를 때 NGU는 +4.3%p 상승했습니다.
- 코딩 태스크(Manufactoria): 14~30개의 까다로운 테스트 케이스를 통과해야 하는 태스크에서 기본 GRPO는 쉬운 테스트만 맞히며 최종 문제 해결률(All-Tests Pass) 0%에 갇혔습니다. 반면 NGU는 어려운 테스트를 집중 공략해 최종 해결률을 약 42%까지 끌어올렸습니다.

마치며:

정말 어려운 문제를 만날 때는 두 가지 선택지가 있습니다. 한 번만 시도하고 포기하거나, 풀 수 있을 때까지 최대한 노력해서 풀어내는 것이죠. 우리는 후자를 선택할 때 성장합니다. 기존 GRPO는 전자를 강요했고, 이 논문에서는 후자의 힘을 증명합니다. 포기해야 되는 어려운 문제를 더 큰 성장의 기회로 보고 학습을 해냈죠.

데이터셋도 학습 알고리즘도 건드리지 않으며, 기존의 GRPO의 장점은 유지하면서 멋진 성능 향상을 이뤄냈습니다. 결과적으로도 철학적으로도 훌륭한 논문입니다!
