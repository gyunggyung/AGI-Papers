---

중소형 모델로 터미널 환경에서 강화학습(RL)을 길게 돌리면, 어느 순간부터 학습이 불안정해져서 오히려 성능이 떨어집니다. 그런데 이걸 재귀적 자가개선(RSI) 구조로 풀 수 있다고 주장하는 논문이 있습니다.

텐센트 연구진이 발표한 논문 "Terminal-RSI: Recursive Self-Improving Terminal Agents via Recursive Self-Rewrite and Policy-Refine"는 흔들리는 RL 중간에 SFT(지도학습)를 끼워 넣어 벽을 깨는 재귀적 자가개선(RSI) 구조를 제시합니다.

핵심은 단순합니다. 외부 데이터 없이 Qwen3.8-27B 모델 스스로 [SFT -> PPO] 과정을 딱 2차에 걸쳐 반복해 성능을 크게 끌어올리는 것입니다.

1. 그냥 RL만 돌리면 무너지는 이유 (0%의 늪과 꼼수)

터미널 에이전트는 실제로 코드를 고치고 빌드를 통과해 최종 검증기(Verifier)를 뚫어야 합니다. 여기에 단순 RL만 적용하면 몇 가지 문제가 생깁니다.

- 단독 RL의 한계: Base 모델에 곧바로 PPO만 돌리면 고난도의 Terminal-Bench 4.0에서 20스텝 내내 0.00%에 머뭅니다. 기초 학습 후 RL을 돌려도 20스텝에서 멈추지 않고 35스텝까지 계속 돌리면 점수가 16.67%에서 11.11%로 도리어 하락합니다.
- 부분 점수의 함정: 기존 보상에서는 최종 실패한 시도들이 전체 보상의 50.09%를 가져갔고, 158개는 실패했는데도 성공 기준점(1.0점)을 넘겼습니다. 완벽한 해결 대신 부분 점수 따기에 안주하는 것입니다.

2. 힌트 세탁으로 만드는 자가 SFT (RSR)

정답률이 0%인데 처음에 어떻게 스스로 SFT 데이터를 만들었을까요? 비결은 연습장의 보조 장치(하네스)와 힌트 세탁 과정인 RSR(Recursive Self-Rewrite)에 있습니다.

- 보조 하네스와 공략집 작성: 어려운 평가 시험장에서는 0%였지만, 3,000개의 학습 데이터에서는 기본 성공률이 21.35%였습니다. 여러 보조 하네스의 도움을 받아 일단 성공한 기록을 모은 뒤, 모델 스스로 핵심 해결 요약본(Runbook)을 최대 4개 쓰게 합니다.
- 힌트 보고 풀고 힌트 지우기: 정답 유출이 없는 요약본을 프롬프트에 비공개 힌트로 넣어주고, 보조 장치가 없는 기본 환경에서 4번 새로 풀게 합니다. 힌트 덕분에 깔끔하게 성공한 기록에서 처음에 넣어줬던 힌트만 싹 지우고 SFT를 진행합니다.

모델 입장에서는 힌트 없이도 단번에 정석대로 푼 과정을 체화하게 되며, 이 1차 SFT(RSR-1)만으로 TB 4.0 점수가 0.00%에서 6.10%로 뚫립니다.

3. 어림잡는 27B 회귀 코치와 턴 단위 평가 (RPR)

SFT로 발판을 만든 뒤에는 선수(Actor)와 코치(Critic)가 함께 뛰는 PPO 강화학습(RPR)을 돌립니다.

- 턴 단위 가치 감쇠 (TB-GAE): 채점은 작업이 다 끝난 뒤 딱 한 번 합니다. 대신 그 점수를 과거 행동들에 나눠줄 때 수천 줄짜리 터미널 로그는 건너뛰고, 명령어를 치고 다음 턴으로 넘어갈 때만 한 번씩 점수를 감쇠시킵니다.
- 회귀 모델로 학습하는 코치: 턴마다 어떤 행동이 최선인지 정답이 없기 때문에, 선수와 똑같은 27B 코치 모델(출력층 Value Head)이 매 토큰마다 최종 예상 점수(0.0~2.0 사이 실수)를 어림잡아 찍어냅니다. 작업이 끝난 뒤 실제 최종 점수와 예상 점수의 오차 제곱(MSE)을 줄이는 회귀 모델처럼 학습합니다.
- 코치 승계와 4스텝 적응: 선수가 SFT를 거칠 때 코치는 초기화하지 않고 그대로 물려줍니다. 단, RL을 시작할 때마다 처음 4스텝은 선수를 고정해 두고 코치만 단독 학습시켜 바뀐 선수에게 눈높이를 먼저 맞춘 뒤, 5스텝부터 둘을 동시에 학습시킵니다. 덕분에 맨 처음 -1.15였던 코치의 예측력(EV)은 2차 RL 때 최고 0.52까지 오릅니다.

4. 2차 RSI(SFT -> PPO -> SFT -> PPO)의 성과

연구진은 RL이 무너지기 전에 SFT로 끊어주는 재귀적 자가개선(RSI)을 2차에 걸쳐 진행했습니다.

- 1차 RSI (RSR-1 -> RPR-1): 1차 SFT 후, 중간 체크만 통과해도 후하게 부분 점수(FDR)를 주는 1차 PPO를 돌리고 정점인 20스텝에서 딱 멈춥니다.
- 2차 RSI (RSR-2 -> RPR-2): 1차 PPO가 새로 찾은 성공 경로들을 다시 힌트 세탁해 2차 SFT로 단단히 굳힙니다. 이어지는 2차 PPO에서는 기존 지식을 잊지 않게 선수 학습률을 5분의 1(5e-7 -> 1e-7)로 낮추고, 실패하면 무조건 1.0점 미만, 완벽히 성공해야만 1.0~2.0점을 주는 엄격한 보상(SPR)으로 바꿔 18스텝 동안 조입니다.

이 2차 RSI를 거치며 Terminal-Bench 4.0, 3.0, 2.1, Hard 벤치마크 평균 점수는 20.68%(Base) -> 34.25%(RSR-1) -> 44.50%(RPR-1) -> 48.75%(RSR-2) -> 50.58%(RPR-2)로 2.5배 상승했습니다. 가짜 고득점 실패는 158건에서 0건으로 사라졌고, 평균 대화 턴 수는 50턴에서 116.8턴으로 늘며 끝까지 오류를 잡는 끈기가 생겼습니다. 27B 크기로 TB 4.0(19.84%)에서 Gemini 3.8 Flash(19.70%)를, TB 2.1(86.52%)에서 GPT-6 Sol(85.40%)과 Kimi K3(85.00%)를 넘어섰습니다.

마치며:

RSI를 3차, 4차 무한히 돌릴 수 있는 건 아니고 2차 사이클에서 상승세가 꺾이며 한계를 보입니다. 고정된 3,000개 문제 안에서 자기 출력물만 재학습하는 구조의 한계 같습니다.

다른 RSI를 주장하는 논문들과 마찬가지로 현시점에는 LLM의 무한한 자가개선은 불가능한 것 같네요.

하지만 단일 RL만 돌리면 쉽게 무너지는 터미널 환경에서, RL이 흔들리기 직전에 자가 SFT로 지식을 굳히고 보상 허들을 높여가는 이 2차 RSI 구조는, 터미널뿐 아니라 다른 RL 과정에서도 차용할 아주 좋은 아이디어 같습니다.
