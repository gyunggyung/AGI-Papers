title: "AgentOPSD: 멀티턴 에이전트 강화학습을 위한 턴 단위 기여도 정밀 평가 (Recursive Self-Distillation)"
---

요즘 Claude Code나 Codex 같은 코딩 에이전트를 사용할 때, 에이전트가 수십 턴에 걸쳐 개발 환경과 상호작용하며 문제를 푸는 일은 흔합니다. 그런데 기존 강화학습(GRPO)에는 결정적인 구조적 결함이 있었습니다.

최종 과제 성공/실패 여부에 따른 보상(Reward)을 모든 턴에 똑같이 나눈다는 점입니다 (Uniform Credit). 10번째 턴에서 치명적 실수를 해도 결과가 좋으면 칭찬받고, 5번째 턴에 결정적 해법을 냈어도 실패하면 벌을 받습니다. 이 무성의한 보상 배분은 상호작용 턴 수가 길어질수록 에이전트 지능을 무너뜨리는 주범이 됩니다.

칭화대, 절강대, 메이퇀(Meituan) 연구진이 발표한 논문 "AgentOPSD: Recursive Self-Distillation for Agentic Reinforcement Learning"은 별도 가치 평가 모델이나 추가 롤아웃 없이 매 턴의 기여도를 정밀 산출하는 해법을 제시합니다.

1. 방법론의 핵심: Self-Teacher와 베이지안 누적 신뢰도

가치 평가 모델 없이 각 턴의 공로를 판별하는 핵심은 '동일 모델의 프롬프트 분기'와 '베이지안 상태 추적'입니다.

 - Self-Teacher(셀프 티처)란?
별도의 거대한 외부 모델이 아닙니다. 학습 중인 자기 자신입니다. 차이점은 단 하나, 학습 시에만 교사 브랜치 프롬프트에 '유용한 스킬/서브골 지침'을 슬쩍 추가합니다.

학생 브랜치(기본 프롬프트)가 출력한 행동을 교사 브랜치에 똑같이 입력하여, "힌트가 있을 때도 이 행동의 확률이 높은가?"를 비교합니다. 이 로그 확률의 차이가 해당 턴의 단기 증거 점수가 됩니다.

 - 베이지안 누적 신뢰도 (Recursive Belief Update)
단기 증거 점수만 보면 이전 상호작용 맥락을 놓칩니다.

AgentOPSD는 문제의 기본 난이도(그룹 평균 성공률 B_0)를 출발점 삼아, 매 턴의 증거 점수를 지수 감쇠(gamma=0.95)로 누적하여 "현재 시점에서 최종 성공할 추정 확률(B_k)"을 계산합니다.

 - 결정적 턴(Pivotal Turn)의 추출: Delta B_k
핵심은 B_k 자체가 아니라, 이전 턴 대비 성공 추정 확률의 변화량(Delta B_k = B_k - B_{k-1})입니다.

성공 확률을 +5%에서 +40%로 급격히 끌어올린 턴이 있다면, Delta B_k 수치가 매우 크게 나옵니다. 바로 이 턴이 전체 에피소드를 성공으로 이끈 핵심 턴입니다.

2. 보상 재배정 (Advantage Reshaping)

각 턴의 Delta B_k를 구했다면, 최종 검증기(Verifier)의 보상 신호와 결합하여 GRPO의 보상을 재조정합니다. 성공을 견인한 턴에는 가산점을, 실패로 비튼 턴에는 삭감합니다.

궤적 내에서 이 값을 정규화한 뒤 [1-b, 1+b] 범위(기본값 b=0.2)로 제한하여, 기존 GRPO의 보상 신호를 턴별로 0.8배~1.2배 사이에서 정밀하게 재조정합니다.

3. 시스템 및 비용 효율성: "생성 비용 0원"

이 과정에서 텍스트를 하나씩 뽑는 비싼 생성 연산(롤아웃)은 기존 GRPO와 100% 동일하며, 가치 평가용 신경망(Critic)도 따로 훈련하지 않아 추가 GPU 생성 비용이 0원입니다.

교사 브랜치는 이미 완성된 텍스트 전체를 한 번에 입력받아 확률만 조회하므로 연산량이 매우 적습니다.

수식 계산과 베이지안 업데이트는 순수 CPU 연산 수준이라, 전체 시스템 오버헤드는 단순 Forward Pass 1회 추가에 불과합니다.

4. 숫자로 보는 성능과 턴 수 유지력

Qwen2.5 (3B, 7B) 모델 기반으로 8장 내외의 H800 GPU 환경에서 단 150 Step 학습을 진행한 결과입니다:

 - ALFWorld (최대 50턴 가사 에이전트): Qwen2.5-7B 기준 89.1% 성공률 (기존 GRPO 81.2% 대비 +7.9%p)

 - WebShop (최대 15턴 쇼핑 에이전트): 79.7% 성공률 (GRPO 72.6% 대비 +7.1%p)

 - Search-QA (최대 4턴 검색 QA): 49.2% 정확도 (GRPO 42.0% 대비 +7.2%p)

이 논문의 진짜 가치는 상호작용이 길어질 때의 방어력에 있습니다.

성공한 에피소드의 평균 턴 수가 1턴 늘어날 때마다 감소하는 성공 포인트(OLS 기울기)를 측정한 결과:

 - 기존 GRPO: 추가 1턴당 -2.91점 급락

 - 기존 Self-Distillation(RLSD): 추가 1턴당 -3.59점 급락

 - AgentOPSD: 추가 1턴당 단 -0.54점 감소

상호작용이 20~50턴으로 길어져도 보상 신호가 희석되지 않고 끝까지 성능을 유지함을 증명했습니다.

5. 논문의 한계점

다만 실험 설계 측면에서 프리프린트 논문다운 아쉬운 한계도 분명 존재합니다.

 - 초단기(2~3턴) 실험의 부재: 논문에서 가장 짧은 과제는 4턴 제한의 Search-QA입니다. 2~3턴 수준의 짧은 대화나 단발성 툴 호출 환경에서는 기존 GRPO 대비 성능을 알 수 없습니다.

 - 회귀 분석의 한계: 턴 수 유지 성능 실험을 다양한 환경으로 확장하지 않고, ALFWorld 내부 하위 과제들의 턴 수 편차를 이용해 OLS 회귀 기울기로만 추정한 점은 한계로 지적될 수 있습니다.

 - 연산 자원 실험 부재: 장비 사양과 150 Step이라는 정보만 있을 뿐, GRPO 대비 실제 소요된 학습 시간(GPU Hours) 측정 데이터는 빠져 있습니다.


마치며

멀티턴이 필수인 현대 에이전트에게, 결과 보상만 뭉뚱그려 던져주던 기존 GRPO는 분명한 한계가 있었습니다.

AgentOPSD는 프롬프트 차이에 따른 턴별 확률 변화를 베이지안으로 누적한다는 아이디어로 50턴짜리 장기 에이전트의 성능을 끌어올렸습니다.

복잡한 다중 턴 에이전트를 설계 중이라면, 롤아웃 횟수를 늘리기 전에 턴 단위 평가가 제대로 이뤄지고 있는지 되돌아볼 필요가 있습니다. AgentOPSD를 사용하지 않더라도 말이죠.

앞으로도 이런 멀티턴 관련 연구들이 늘어나면 좋겠네요!
