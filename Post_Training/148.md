title: "Normalized Low-Rank Adaptation (NoRA): 행렬 정규화 한 줄로 LoRA의 성능과 안정성을 극대화하다"
---

우리가 LLM을 튜닝할 때 흔히 사용하는 LoRA는 초반에 학습이 더디고, 사전 지식을 망각하거나 강화학습에서 불안정하게 흔들립니다. 그런데 LoRA에 정규화만 해도 이 문제가 완화된다는 것을 알고 계셨나요?

최근 Yuanshi Intelligence, 홍콩중문대(CUHK), Microsoft Research 연구진이 발표한 논문 "Normalized Low-Rank Adaptation (NoRA)"는 아주 단순한 행렬 정규화 한 줄로 LoRA의 성능과 안정성을 크게 끌어올린 결과를 보여줍니다.

1. LoRA 초반 학습의 숨겨진 병목: 왜 A 행렬이 문제인가?

기존 LoRA는 가중치 변화량을 두 개의 작은 행렬의 곱(\Delta W = B \times A)으로 만듭니다. 기존 모델의 지식을 보존하기 위해 뒤쪽 행렬인 B(Up-projection)는 0으로 초기화하고, 앞쪽 행렬인 A(Down-projection)는 무작위 정규분포(가우시안 랜덤)로 채워 넣고 시작하죠. 여기서 문제가 발생합니다.

- 나침반 역할을 홀로 떠맡은 A: 초기에 B가 0이기 때문에 미분을 해보면 A 행렬의 학습 기울기(Gradient)는 완전히 0입니다. 반대로 B는 A가 만들어둔 길을 따라 첫 발을 뗍니다. 즉, 초반 학습 방향과 속도를 순전히 운에 맡겨진 무작위 A가 결정하는 구조입니다.
- 턱없이 작은 유효 학습률: 수학적으로 뜯어보면 A 행렬의 열(기둥) 크기가 곧 입력 데이터 좌표별 유효 학습률(Learning Rate) 역할을 합니다. 그런데 기존 무작위 초기화에서는 이 기둥들의 크기가 너무 작고 좌표마다 제각각 널뜁니다. 전체 모델을 직접 파인튜닝할 때와 비교하면 신호가 턱없이 약하게 들어가서 초반 학습이 비효율적일 수밖에 없습니다.

2. 해결책은 단순하다: A의 기둥 길이를 1로 맞춰라 (NoRA)

DeepSeek의 MLA 구조 등에서 잠재 병목을 정규화하면 학습이 매우 안정된다는 점은 이미 알려져 있었습니다. 하지만 중간 표현을 직접 정규화하면 수식이 비선형이 되어, 학습이 끝난 뒤 LoRA의 가장 큰 장점인 원래 가중치에 덧셈으로 쏙 합치는 기능(가중치 병합)이 사라집니다.

NoRA 연구진은 입력 데이터를 건드리지 않고, A 행렬 자체의 세로 기둥(열 벡터) 크기를 딱 1로 정규화(L2-Norm)해 버렸습니다. B * A를 B * Norm(A)로 바꾼 것뿐이죠.

- 풀 파인튜닝급 학습 신호 복원: 기둥 길이를 1로 고정하자마자 입력 좌표별로 널뛰던 학습률 왜곡이 평평하게 펴집니다. 추가 파라미터나 복잡한 계산 없이도, 초반부터 모델 전체를 파인튜닝할 때와 맞먹는 강력한 그래디언트가 흐르게 됩니다.
- 완전한 가중치 병합 유지: 가중치 행렬만 정규화했기 때문에 선형성이 그대로 유지됩니다. 학습이 끝나면 기존 LoRA와 똑같이 기본 모델에 그대로 덧셈 병합할 수 있습니다.

3. 숫자와 실험으로 보는 효과

이 단순한 교정의 효과는 벤치마크 전반에서 뚜렷하게 나타납니다.

- 지도학습(SFT) 성능 대폭 향상: LLaMA-3.2-3B 기준 SFT 평균 점수가 표준 LoRA 37.93점에서 NoRA 43.37점으로 5.44점 상승했습니다. 특히 수학(GSM8K)은 50.94점에서 61.63점으로 10.69점 올랐고, 코딩(HumanEval)도 37.20점에서 42.10점으로 올랐습니다.
- 치명적 망각(Catastrophic Forgetting) 방지: 파인튜닝 중 기존 상식 시험(MMLU, AGIEval, ARC-C) 점수 변화량이 LoRA는 -0.56점 깎인 반면, NoRA는 +0.02점으로 기존 사전 지식을 안정적으로 지켜냈습니다.
- 강화학습(RLVR)에서의 붕괴 방지: DeepSeek-R1-Distill-Qwen-1.5B 기반 수학 추론 강화학습에서 PiSSA(0.2점), MiLoRA(18.0점) 같은 SVD 기반 기법들은 최적화가 심각하게 붕괴했습니다. 반면 NoRA는 붕괴 없이 44.4점을 기록하며 표준 LoRA(42.8점)보다 높은 성능을 증명했습니다.

4. 시작할 때 딱 한 번만 정규화해도 충분하다 (NoRA-init)

"그럼 학습 내내 매 스텝마다 정규화를 돌려야 하나요?" 꼭 그렇지는 않습니다. 초반 방향 정렬이 핵심이기 때문에, 훈련을 시작할 때 딱 한 번만 A를 정규화해두고 이후에는 표준 LoRA처럼 학습시키는 NoRA-init 방식도 제안되었습니다.

실제로 NoRA-init은 학습 도중 아무런 추가 연산을 하지 않음에도 SFT 평균 42.38점을 기록하며 전체 상승폭(43.37점)의 80% 이상을 그대로 가져갔습니다. 심지어 단위 행렬들을 이어 붙여서 처음부터 기둥 길이가 1이 되게 만든 블록 단위 행렬 초기화(BIMI) 역시 NoRA-init과 대등하게 동일한 효과를 냅니다.

그래도 매 스텝마다 정규화를 해주는 NoRA가 더 좋은 성능을 보입니다.

마치며:

복잡한 SVD를 동원하거나 추론 지연을 유발하는 화려한 기교 없이, 초기화의 기하학적 불균형을 수식으로 규명하고 단 몇 줄의 정규화로 문제를 해결한 깔끔한 연구입니다.

LoRA 파이프라인을 운영할 때 코드 수정 거의 없이 A 행렬 초기화만 단위 벡터로 맞춰주면 되니, 앞으로 LoRA의 표준이 될 것 같습니다. 다만 최대 3B 수준에서 실험한 논문이니 만큼, 100B 이상의 거대 모델에서는 어떻게 동작할지 확인이 필요해 보입니다.
