title: "MoE 라우팅의 한계를 넘어: ReMoE(ReLU 라우팅)와 AoE(자율 전문가 모델)"
---

이전 글에서도 언급했지만, MoE의 라우팅 방식은 매우 단순합니다. 라우팅 행렬을 만들고, 입력 토큰에 내적을 해서 나온 점수로 전문가를 Top-K개로 자르고 Softmax로 비율로 나누죠. 문제에 적합한 Top-K도 선택할 수 없고, 전문가의 웨이트를 보지도 않죠.

이러한 단순한 MoE 라우팅의 한계를 넘어, 더 유연하고 자율적인 MoE로 진화하기 위해 Top-k에서 벗어나 ICLR 2025에 채택된 ReMoE와 라우터 모듈을 없애 ICML 2025에 채택된 AoE를 소개드리겠습니다.

1. ReMoE (Fully Differentiable Mixture-of-Experts with ReLU Routing)

기존의 Top-K 라우팅 방식은 상위 몇 개를 칼같이 잘라내는 방식이라 수학적으로 불연속적이고 미분이 불가능했습니다. 이 때문에 역전파를 통한 모델 학습에 한계가 있었죠. 

라우터가 가중치를 조금 업데이트해서 전문가 선택(상위 K개)이 [전문가 A, B]에서 [전문가 B, C]로 바뀌는 순간, 모델의 결괏값이 부드럽게 변하는 것이 아니라 갑자기 확 점프해버립니다.

이러한 불연속성 때문에 역전파 시 라우터 파라미터에 "어느 방향으로 가중치를 수정해야 더 똑똑하게 전문가를 고를 수 있는지" 알려주는 기울기(Gradient)가 끊기거나 왜곡되는 문제(False Gradient)가 발생합니다. 즉, 라우터가 오차 피드백을 제대로 받지 못해 학습 자체가 비효율적이었습니다.

게다가 토큰이 아주 쉬운 단어('the', '\n' 등)이든 고난도의 수학 공식이든 상관없이 무조건 강제로 K개의 전문가를 할당해야 하는 비효율이 존재했습니다.

ICLR 2025에 채택된 ReMoE는 거추장스러운 Softmax와 Top-K를 빼버리고, ReLU 활성화 함수를 라우터에 도입했습니다.

내적 값이 0보다 크면 활성화되고, 0 이하면 꺼지는 아주 단순한 방식입니다. 이 작은 변화 덕분에 라우팅 과정이 수학적으로 매끄러워져(미분 가능) 학습이 훨씬 안정되었습니다. 

이제 선택되는 전문가가 바뀌더라도 값이 0 부근에서 부드럽게 전환되므로, 역전파 기울기(Gradient)가 끊기지 않고 라우터에 정확하게 전달됩니다. 

결과적으로 라우터가 눈을 가리고 찍는 식의 학습에서 벗어나, 정밀한 오차 피드백을 온전히 받아들일 수 있게 되어 전체 MoE 네트워크의 학습 과정이 훨씬 빠르고 안정적으로 수렴하게 됩니다.

loss를 줄이기 위해 모든 전문가를 다 켜버리려고 하는 문제가 있기에, ReMoE 연구진은 목표한 희소성을 맞추기 위해 "라우터의 출력값을 최대한 0으로 끌어내리라"는 페널티(L1 Regularization)를 지속적으로 줍니다. 

거기다 모델은 학습을 거듭할수록 스스로 "쉬운 단어는 전문가 1명의 점수만 0 이상으로 켜두고, 어려운 단어는 전문가 4명의 점수를 0 이상으로 켜두자"는 식의 난이도에 따른 동적 할당(Dynamic Allocation) 메커니즘을 자연스럽게 터득하게 됐습니다.

2. AoE (Autonomy-of-Experts Models)

기존 구조에서 라우터는 전문가 모듈 외부에 존재합니다. 즉, 라우터는 각 전문가들이 내부적으로 어떤 능력을 갖추고 있는지 정확히 모른 채 간접적인 학습에 의존해 토큰을 던져주는 추측성 배정을 할 수밖에 없습니다. 잘못된 토큰을 받은 전문가는 억지로 그 토큰에 맞춰 파라미터를 수정하게 되고, 결과적으로 전문성이 깎이는 문제가 발생합니다. 

거기다 추론 과정에서도 수학 문제에 번역을 잘하는 전문가를 선택하는 잘못된 선택을 하기도 쉽습니다.

ICML 2025에 채택된 AoE는 "전문가 스스로가 자신의 능력을 제일 잘 안다"는 발상으로 중앙 라우터를 완전히 없애버렸습니다.

대신, 입력 토큰이 들어오면 모든 전문가가 일단 연산을 살짝 해보고 스스로를 평가합니다. 특정 토큰에 대해 자신이 가진 지식과 잘 맞으면 내부의 활성화 크기(Activation Norm)가 커진다는 점을 이용한 겁니다. 

수학적으로 내적은 두 벡터가 비슷한 패턴을 가질 때 그 값이 폭발적으로 커집니다. 즉, 입력값 x와 가중치 W를 내적한 값이 크다는 것은 해당 전문가가 가진 가중치 패턴이 현재 들어온 토큰 입력값과 잘 맞는다는 것을 의미합니다.

모든 전문가가 각자 이 활성화 크기를 계산해내면, 단순히 이 크기를 기준으로 줄을 세워 상위 K개의 전문가만 선정합니다. 그리고 선택된 전문가들만 최종 연산을 끝까지 수행하고, 선택받지 못한 나머지 전문가들은 그 즉시 연산을 멈추고 종료합니다. 라우터의 예측이 아니라 전문가들의 실력 입증으로 할당 방식을 대체한 것이죠.

하지만 모든 전문가가 입력값을 받아 연산을 시도하면 연산량 부담이 커집니다. 이를 해결하기 위해 AoE 연구진은 전문가 FFN의 첫 번째 선형 계층 가중치 행렬을 저차원(Low-rank) 행렬 두 개(압축용 행렬, 복원용 행렬)로 분해했습니다. 

모든 전문가는 입력 토큰을 원래 모델 차원의 약 3분의 1(1/3) 수준으로 얇게 압축하는 가벼운 1차 연산만 우선 수행합니다. 이렇게 3분의 1 크기로 압축된 활성화 벡터를 바탕으로, 각 전문가는 자신의 L2 노름(Norm) 크기를 계산해 상위 K개를 선발합니다.

이렇게 1차 연산에서 활성화 벡터를 압축하고, 선택된 Top K개 전문가들만 아까 만들어둔 압축 벡터를 두 번째 복원용 행렬과 곱해 원래 차원으로 복원(압축 해제)하며 최종 FFN 연산을 마무리합니다. 해당 방법론으로 기존 MoE 대비 97%의 처리량을 보여주면서도, 성능 향상을 이뤄냈습니다.

결과적으로 라우터와 전문가가 분리되어 발생하던 학습 낭비가 사라졌고, 각 전문가는 자신이 진짜 잘하는 토큰만 자율적으로 골라 처리하며 고도로 전문화될 수 있었습니다.

다음에는 AoE를 개선한 UoE, 그리고 ReMoE의 중앙 라우터, AoE, UoE의 Softmax와 TopK 문제를 모두 해결한 RFMoE를 다뤄보겠습니다. 이후에 NVIDIA의 LatentMoE와 Kimi (Moonshot AI)의 Kimi K3로 현대 MoE의 끝판왕들을 다뤄보겠습니다.
