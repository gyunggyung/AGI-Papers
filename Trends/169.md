---

최근 제 피드에서도 자주 보이는 Jev는 일반화가 잘 된 대형 BERT에 가까워 보입니다. 그런데 ChatGPT가 나왔을 때도 기존에 있던 걸 크게 만들고 쓰기 좋게 만든 것 뿐이라는 말을 들어본 것 같습니다.

과거 분류 모델은 SVM이나 Random Forest부터 시작해 BERT의 파인튜닝 시대를 거쳤습니다. GLiNER 같은 제로샷 시도도 있었지만, 롱 컨텍스트에 복잡한 작업에서는 체급의 한계가 명확했죠.

마치 GPT-2 시절 파인튜닝에 의존하다가 GPT-3의 거대화로 일반화를 이루고 InstructGPT의 포맷 정렬과 인간 선호도 학습(RLHF)으로 ChatGPT가 시장을 장악했듯, Jev는 그 공식을 판별형 모델에 그대로 복사했습니다.

RLHF를 만들었던 OpenAI의 전 핵심 연구원이 만든 서비스 답게, 화려한 마케팅, 쓰기 좋은 UX, 거기다 거대화와 의사결정 강화학습(RLCD)을 통해 별도 튜닝이 필요 없는 일반화된 대형 BERT를 상용화한 것입니다.

이제 허깅페이스와 GitHub에는 Jev의 기능을 오픈웨이트 모델들로 구현한 프로젝트들이 쏟아져 나오고 있습니다. Jev가 무엇이고, 왜 ChatGPT의 역사와 평행이론을 달리는지, 그리고 오픈 모델들이 어떻게 따라잡고 있는지 간단하게 살펴보겠습니다.

1. Jev는 왜 그렇게 빠를까? (생성 루프의 거세)

일반적인 LLM은 "예/아니오" 하나를 답하려 해도 JSON 괄호를 열고 닫으며 토큰을 한 글자씩 뱉어내야 합니다. 반면 Jev는 텍스트 생성을 완전히 제거했습니다.

긴 시스템 상태(State)를 읽은 뒤, 사전에 정의된 선택지(Choice), 참/거짓(Noul), 점수(Score) 슬롯에 단 1번의 연산으로 확률값만 찍어냅니다.

- 지연 시간: 70ms ~ 500ms
- 입력 비용: 100만 토큰당 $0.042
- 출력 비용: 무료

뱉어내는 텍스트 토큰 자체가 없으니 출력 비용은 0원이고, 지연 시간은 밀리초 단위로 끝납니다.

2. ChatGPT와의 기묘한 평행이론 (OpenAI 출신의 공식)

Jev를 만든 TypeSafe AI의 Diogo Almeida는 OpenAI 출신이자 초기 RLHF의 핵심 연구자였습니다. 그 이력을 알고 나면 Jev의 정체가 더 잘 보입니다.

- 거대화와 UX: GPT-3.5에 채팅 UX를 입혔듯, 모델을 거대화하고 개발자 친화적인 타입 인터페이스(Choice, Score, Noul)를 입혔습니다. 실제로 사용하기 좋은 API로 큰 호평을 받고 있습니다.
- 데이터 중심 설계와 RLCD: 대규모 합성 데이터에 의사결정을 위한 강화 학습 (RLCD)을 더해, 다양한 도메인에서도 동작하는 일반화된 모델을 만들었습니다.
- 화려한 리브랜딩: 기존 인코더와 분류 기술을 "새로운 클래스의 System 1 모델", "Neither small nor an LLM"이라는 이름표로 포장했습니다. 시장을 정의하는 방법을 정확히 알고 있는 셈입니다.

3. ChatGPT 독점 뒤에 LLaMA가 있었듯: 오픈소스의 반격

Jev가 유료 API를 내놓자마자 오픈소스 진영이 빠르게 반격에 나섰습니다. 기존의 모델들을 활용하는 다양한 접근법들이 나왔습니다.

- convaiinnovations/laya (전용 경량 인코더): Convai는 2025년 3월 이미 PPO로 의사결정 확률을 뽑는 선행 논문을 냈던 Jev의 원조격입니다. Jev 출시 3일 만에 ModernBERT 기반의 421M 모델을 허깅페이스에 공개했는데, T4 GPU에서 32.8ms로 Jev API(236ms~)보다 7배 이상 빠르고 자체 벤치마크 정답률도 76.6%로 Jev(72.7%)를 앞섰습니다. (단, 확률 정밀도는 대형 백본인 Jev가 우세) 현재 허깅페이스 모델 트렌드 1위를 달리고 있습니다.
- harshatheg/Qwen-2.5-1B-RLCD (아키텍처 개조 + RLCD): 사전 학습이 충분히 잘 된 LLM인 Qwen의 마스크를 풀고 Brier Score 손실을 적용해 확률 보정(RLCD)을 직접 구현했습니다. 모델이 틀리면서도 99% 확신하는 과신(Overconfidence) 문제를 잡는 오픈 레시피를 입증했습니다.
- nokia-applied-research/AnyJev (학습 프리 접근법): "새로 학습할 필요 없이 이미 서빙 중인 Qwen3의 로짓만 영리하게 읽자"는 GitHub 프로젝트입니다. 선택지 순서만 뒤집어도 답이 바뀌는 고질적인 위치 편향을 순환 순열(Cyclic Shift)로 잡았습니다. 추가 학습 없이 통계적 보정만으로 5% 이하 에러율로 자동화 가능한 의사결정 트래픽을 7.7%에서 52.0%로 6.8배 끌어올렸습니다.

당연한 말이지만, 이외에도 많은 시도들이 있습니다.

개인적인 생각으로 Qwen3.5 9B나 Gemma4 12B 같은 10B급 오픈 모델을 AnyJev 스타일 의사결정 모델로 변환한 뒤, Jev 증류 + RLCD를 진행하면 Jev와 대등한 오픈 모델을 만들 수 있지 않을까 싶습니다.

마치며:

오픈소스가 아무리 쏟아져 나와도 OpenAI가 업계 정상을 지키듯, Jev 역시 시장에서 독보적인 위치를 차지할 가능성이 높습니다.

항상 생각하는 건데, 기술 자체보다는 브랜딩, 마케팅, UX 같은 요소들이 더 중요한 것 같습니다. 그럼에도, 기술을 기반으로 하는 것들은 기술이 좋으면 좋을 수록 고점이 좋기에 기술의 가치는 중요하죠.

2022년 말 OpenAI의 ChatGPT가 나오기 전까지는 NLP 분야에서도 Bert 중심의 분류기가 더 많은 주목을 받았었습니다. 그런데 2026년 OpenAI 연구원 출신이 만든 Jev로 인해 다시 분류기가 주목을 받는 모습도 재밌네요. 더 많은 모델들이 나오길 기대합니다.
