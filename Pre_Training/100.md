title: "Breaking the Token Ceiling: 256개 순수 바이트로 토큰 천장을 뚫는 사전학습 지식 증류"
---

컴퓨터의 기본 단위인 1바이트는 256가지(0x00 ~ 0xFF) 상태만 가집니다. UTF-8은 이를 조합해 세상의 모든 문자를 표현하므로, LLM 역시 256개의 어휘 사전만 있으면 어떤 문자든 처리할 수 있습니다.

지식 증류(Distillation)를 이용해 거대한 토크나이저를 버리고 256개의 순수 바이트만으로 모델을 만들면 어떨까요? 데이터는 1/6, 저장 공간은 1/5로 줄이면서도 성능은 4.0%p 더 높습니다.

수만, 수십만 가지 어휘를 쓰는 기존 토큰 방식은 아무리 데이터를 부어도 언젠가 성능이 정체되는 '토큰 천장'에 갇힙니다. 반면 바이트 모델은 잠재력이 무궁무진하지만, 일반 지도학습(NTP)으로는 초반 수렴이 너무 느려 실전성이 떨어졌습니다. Meta FAIR와 워싱턴 대학교 연구진의 논문 "Breaking the Token Ceiling: Distilling Smaller, Stronger Byte Models"는 이 난제를 학습을 마친 모델의 지식 증류로 정면 돌파했습니다.

1. 일반 학습의 한계와 증류가 만든 역전 드라마

바이트 모델은 어휘 사전이 UTF-8 1바이트가 표현할 수 있는 전체 정수 범위인 256개(0x00 ~ 0xFF)에 문장의 시작(<bos>), 끝(<eos>), 패딩(<pad>), 미확인(<unk>)까지 더한 260개 남짓이라 임베딩에 낭비되는 파라미터가 없고, 이론상 표현력의 한계가 없습니다.

하지만 순수 지도학습(Cross-Entropy)만 돌리면 초반 연산 구간에서 토큰 모델에 한참 뒤처집니다. 이 고질적인 초기 학습 난제를 해결한 열쇠가 바로 이미 학습된 토큰 모델(Llama 3-8B)의 완성된 지식을 바이트 단위로 수혈하는 사전학습 증류였습니다.

교사의 확률 분포를 가이드 삼아 학습 효율을 끌어올리자, 바이트 모델은 지능이 정체되는 토큰 모델의 천장을 뚫고 올라가 더 높은 다운스트림 벤치마크 상한선에 도달했습니다.

2. 단 한 번의 추론으로 끝내는 지식 증류 (End-Of-Token)

그런데 128,000개 BPE 토큰을 쓰는 교사 모델의 확률 분포를 256개 바이트 모델에 오차 없이 넘겨주는 것은 수학적으로 매우 까다롭습니다. 기존 방식들은 단어 속 바이트 경로를 일일이 계산하느라 교사 모델을 여러 번 반복해서 추론해야 했고, 계산 비용이 감당되지 않았습니다.

연구진은 단어 끝에 <eot>(End-of-Token)라는 특수 토큰을 딱 하나 붙이는 간결한 해법을 고안했습니다.

- 단 한 번의 포워드 패스만으로, 교사 모델의 언어 모델링 확률 분포를 단 1%의 손실도 없이 100% 완벽하게 바이트 확률로 보존해 넘겨주었습니다.
- 이 사소한 토큰 추가가 데이터당 연산량을 약 31% 늘려주며, 결과적으로 바이트 모델이 도달할 수 있는 지능의 최종 상한선을 대폭 끌어올렸습니다.

3. 더 효율적인 결과: 데이터 1/6, 저장 공간 1/5

단순한 아이디어에 그치지 않고, 64장의 H200 GPU 클러스터로 최대 1조 바이트까지 Overtraining을 진행하며 엄밀한 스케일링 법칙을 증명했습니다.

- 성능 상한선 돌파: 스케일링 법칙으로 추정한 최종 평균 다운스트림 정확도에서, 바이트 증류 모델(End-Of-Token-1B)은 동일 레이어 크기의 토큰 증류 모델 대비 4.0%p 더 높은 성능 천장에 도달했습니다. 심지어 수조 개의 토큰으로 과훈련된 오픈 모델인 Llama-3.2-1B(+6.5%p), Gemma-3-1B-pt(+8.1%p), 체급이 두 배인 Gemma-2B(+2.1%p)의 점근선을 모두 넘겼습니다.
- 데이터 효율성: 토큰 증류 모델이 평생 도달할 수 있는 최고 성능을 달성하는 데 필요한 고유 텍스트 데이터가 6분의 1(1/6.35)에 불과했습니다.
- 저장소 혁신: 기존 토큰 증류는 로짓 용량이 너무 커서 상위 몇백 개만 잘라내(Top-k) 저장해야 했습니다. 바이트 모델은 어휘가 261개뿐이라 전체 분포를 온전히 다 저장하고도 저장 공간을 5분의 1로 줄였습니다.

4. "BPB가 낮다고 무조건 똑똑한 것은 아니다"

연구진이 던진 또 하나의 중요한 경종은 손실값(Loss)에 대한 맹신입니다. 학습 중 바이트 모델이 토큰 모델보다 더 낮은 BPB(Bits per Byte)를 달성한 구간에서도, 실제 문제 풀이(벤치마크) 정확도는 토큰 모델에 한참 뒤처지는 역설이 발견되었습니다.

BPB는 정답 확률 하나만 보지만, 실제 벤치마크는 오답들과의 순위 싸움(arg max)이기 때문입니다. 정답 확률이 같아도 오답 후보가 하나라도 더 높게 치고 올라오면 정답률은 0%가 됩니다. 서로 다른 토크나이저를 쓰는 모델을 비교할 때 손실값 하나만 보고 판단하는 것이 얼마나 위험한지 수학적으로 짚어준 셈입니다.

마치며:

이 연구의 본질은 단순히 "토크나이저가 달라도 증류가 된다" 수준에 있지 않습니다. 이미 완성된 토큰 모델의 지식을 지렛대 삼아, 바이트 모델의 고질적 난제였던 초반 수렴 한계를 극복하고 기존 BPE 토크나이저의 잠재력 천장을 깨부순 것입니다.

Meta FAIR가 오랜 기간 밀고 온 "토크나이저-프리(Tokenizer-Free) 및 바이트 아키텍처" 로드맵의 연장선상에서, 지식 증류를 통해 더 완성도 높은 결과를 만들었습니다. 개인적으로 차세대 Muse Spark 모델에 적용될지도 기대되네요.

다만 바이트 단위로 쪼개는 만큼 문장 길이가 4~5배 길어져, 추론(Inference) 단계의 연산 비용과 KV 캐시 메모리 부담이 커진다는 명확한 현실적 한계는 남아있습니다.
