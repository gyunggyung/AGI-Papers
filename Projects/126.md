4달러로 Jev보다 뛰어난 모델을 만들 수 있을까요?

최근 허깅페이스에 Qwen3.5 9B를 Jev처럼 의사결정 모델로 만들고 SFT 과정을 거친 Kev-9B가 공개됐습니다.

참고로 Kev-9B는 Banking77, BoolQ, MultiNLI, AG News, IMDB 등 10개 공개 분류 데이터셋과 합성 정책 데이터로 학습된 모델이고, 학습 코드와 모델 가중치를 모두 공개했습니다.

거기다 Kev GitHub에 RLCD 실험 코드도 있고, 오픈소스 RLCD 구현체들도 여럿 있기에, 이들을 참고해 Gemini 3.8 Flash로 RLCD 학습 코드를 새롭게 구현하고 A100 1대로 학습을 진행했습니다. 그렇게 만든 모델이 Qwev-9B-RLCD입니다.

RL 과정에서 SFT에 사용한 데이터를 재사용하면 과적합이 발생하니, 새로운 4,800건의 데이터를 구축했습니다.

1. 엔터프라이즈 워크플로우 데이터 (LocalLLaMA/typed-decisions)
2. 인간 선호도 LLM Judge 데이터 (allenai/reward-bench)
3. 결정 근거가 없어 1/K 균등 확률을 강제하는 불확실성 데이터 (kev-suites / boolq)
4. 1k~3k 토큰 노이즈 속 핵심 정보를 찾는 NIAH(Needle-in-a-Haystack) 데이터
5. 모호한 경계선 NLI 소프트 라벨 데이터 (alisawuffles/WANLI)

여기에 Brier Score 손실, 비대칭 과신 페널티, 정보 결손 엔트로피 정규화를 결합한 복합 강화학습 손실 함수를 적용했습니다.

이 전 글에서 소개드린 JEV-as-a-Judge의 벤치마크로 Jev와 GPT-6 Astra 그리고 베이스 모델인 Kev-9B와 비교한 결과를 공유드립니다.

1. RewardBench (400건, 대화 선호도/안전성):
- Qwev-9B-RLCD: 99.2% (Jev 1.13: 92.2% / GPT-6 Astra: 93.5% / Kev-9B 베이스: 76.5%)

2. HaluEval (240건, 증거 기반 환각/사실성):
- Qwev-9B-RLCD: 98.8% (Jev 1.13: 87.5% / GPT-6 Astra: 86.7% / Kev-9B 베이스: 93.3%)

3. RM-Bench-Hard (150건, 장황한 오답 및 스타일 편향 저항력):
- Qwev-9B-RLCD: 98.0% (Jev 1.13: 94.0% / GPT-6 Astra: 96.7% / Kev-9B 베이스: 88.7%)

4. JudgeBench (350건, 복잡한 STEM/알고리즘 추론):
- Qwev-9B-RLCD: 41.7% (Jev 1.13: 78.6% / GPT-6 Astra: 93.1% / Kev-9B 베이스: 40.3%)

Kev-9B 대비 일관적인 성능 향상을 보였고, JudgeBench를 제외하면 Jev나 GPT-6 Astra보다도 뛰어난 성능을 보였습니다.

A100에서 문제를 푸는 평균 추론 속도가 168.4ms (0.16초)로 Jev 1.13(152.0ms)과 유사하며, GPT-6 Astra(1,885ms) 대비 약 11배 빠른 속도를 보여줍니다.

하지만 복잡한 STEM 수식과 알고리즘 추론을 요구하는 JudgeBench에서는 41.7%로 무너졌습니다. 어려운 문제에서는 단독으로 쓸 수 없습니다.

다만 모르는 문제 앞에서는 확신도를 스스로 42% 수준으로 낮추도록 학습되어, 확신도가 높은 것(0.9 이상)만 골라낼 때의 정확도는 97.1%가 나옵니다. 쉬운 분류나 환각 검증은 168ms 만에 쳐내고, 어려운 문제만 거대 모델로 넘기는 캐스케이드 용도로 쓰기에는 충분히 실용적인 것 같습니다.

참고로 여러 시행착오와 평가 때문에 4달러가 나온 것이지 순수 학습 시간은 30분 정도로 1달러도 들지 않습니다. A100 한 대로 4,800개의 데이터를 1에폭 학습을 진행했습니다. 특정 문제를 잡고 관련된 데이터를 모을 수 있다면, 누구나 Jev 보다 나은 모델을 만들 수 있을 것 같습니다.

Jev 자체의 구조가 단순하고, 공개된 자료들이 많으니 만들 수 있을 것 같아서 한 번 만들어본 프로젝트입니다. 구조에 대한 이해도 부족하고, 가볍게 만들었지만 괜찮은 결과를 만들었습니다. 이는 오픈소스 커뮤니티의 힘이라고 생각합니다.

모든 자료를 공개해준 Kev 개발자 Jared Palmer님과 기여자 분들 감사합니다. 그리고 이 프로젝트는 전에 Simon Lee 님에게 받았던 VESSL AI 크레딧으로 진행했습니다. VESSL AI 팀과 Simon님에게도 감사함을 전합니다!
