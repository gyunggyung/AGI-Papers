---

MiMo-V2.6-Pro는 DeepSeek-V3보다도 단순한 모델 구조로 AAII에서 오픈웨이트 모델 중 최고점이자, Grok 4.7과 동점인 46점입니다. LLM의 모델 성능은 아키텍처가 아닌 데이터와 강화학습이라는 것을 증명했습니다. 샤오미가 공개한 "MiMo-V2.6: Scaling Reinforcement Learning Towards Self-Improvement" 내용을 같이 보시죠.

1. 단순하고 효율적인 아키텍처 (SWA + GA MoE)

MiMo-V2.6-Pro는 1.02T A42B 모델로 백본 구조는 신기할 정도로 기본에 충실합니다.

- SWA + GA 하이브리드: 128 토큰만 보는 가벼운 SWA와 시퀀스 전체를 보는 GA를 6:1 비율로 교차 배치했습니다. 대부분의 층에서 연산량을 선형으로 줄이면서도 주기적인 GA를 통해 최대 100만(1M) 토큰의 초장문 문맥을 안정적으로 잇습니다.
- 순수 MoE: 공유 전문가 없이 토큰당 8개의 전문가만 뽑아 쓰는 표준 MoE입니다.

구조를 덜어내 연산 효율을 극대화하고, 여기서 아낀 모든 리소스를 학습 파이프라인에 올인했습니다.

2. RL의 발판을 닦는 Mid-Training

일반적으로 Post-training은 Pre-training에서 배운 지식을 정렬하는 역할만을 한다고 합니다. 그 사이에 에이전트가 동작하는 방식을 이해할 수 있는 Mid-Training을 진행했습니다.

- 에이전트 경로 데이터 주입: 코딩, 업무, 시각, 리서치 등 실제 에이전트가 도구를 쓰며 문제를 해결해 나간 단계별 궤적을 대량으로 주입했습니다.
- 문맥 길이 1M 확장: 256K에서 시작해 100만 토큰까지 문맥을 늘려 장기 기억의 한계를 없앴습니다.
- Muown 옵티마이저: 뒤이어 진행될 대규모 배치 강화학습에서 효율이 떨어지는 AdamW 대신, 은닉층에 행 단위 노름 정규화(Row-norm control)를 추가한 Muown으로 전환해 손실 급등(Loss spike) 없이 최적화 효율을 유지했습니다.

3. 스케일이 다른 강화학습 (스텝당 30억 토큰)

MiMo는 RL을 단순한 사후 정렬이 아니라 사전 학습 수준의 연산량으로 밀어붙였습니다. Pro 모델의 RL 훈련에만 약 260만 달러가 투입되었습니다.

- 초대형 배치: 1스텝에 1,568개 프롬프트 x 16개 롤아웃 = 총 25,000개 궤적을 뽑아내며, 스텝당 무려 27~37억 개의 토큰을 학습했습니다.
- 롤아웃 비용 44%: 전체 비용의 44%를 모델이 직접 환경과 부딪치며 경험을 쌓는 롤아웃에 썼습니다.
- 라우터 고정(Router Freezing): RL 도중 특정 전문가로 연산이 쏠려 OOM이 터지는 '부하 붕괴'를 막기 위해, SFT에서 완성된 MoE 라우터를 고정하고 전문가 가중치만 학습시켜 안정성을 잡았습니다.

4. 100턴이 넘는 멀티턴 환경과 정교한 보상 설계

에이전트 과제(DeepSWE 등)는 문제 하나를 풀기 위해 평균 100~130턴 이상의 대화와 도구 호출을 주고받으며, 궤적 하나당 10만~15만 토큰을 소모합니다.

단순히 '최종 테스트 통과(1점), 실패(0점)' 식의 기본 GRPO를 쓰면, 모델은 테스트만 넘기려고 온갖 꼼수 코드를 덕지덕지 붙이며 턴 수가 130턴 이상으로 폭증해 성능이 무너집니다. 연구진은 두 가지로 이를 통제했습니다.

- 토큰 단위 세그먼트 페널티: 중간 턴에서 잘못된 도구를 호출하거나 포맷을 어긴 토큰을 마스킹하고, 성공 궤적에서는 에러 없는 정상 토큰에만 보상을 몰아주었습니다.
- Grader Agent(채점기 에이전트) 투입: SFT 체크포인트로 별도 띄운 고정 채점기 에이전트가 성공한 코드들을 상호 비교합니다. 접근의 적절성, 코드의 최소성, 부작용 방지 등을 평가해 '가장 군더더기 없이 간결하게 푼 궤적'에 보상 가중치(어드밴티지)를 재분배했습니다.

그 결과 턴 수가 105~112턴 안팎으로 유지되며 불필요한 장황함 없이 실무 수준의 깔끔한 코드를 작성하게 되었습니다.

5. 멀티 하네스(Multi-Harness)와 환경 공개

특정 에이전트 인터페이스에 과적합되는 것을 막기 위해, 시스템 프롬프트와 도구만 남긴 4종의 미니 하네스를 섞어 훈련했습니다. 그 덕분에 학습 때 보지 못했던 Claude Code, Codex 같은 외부 상용 프레임워크에서도 평균 50%에서 66%로 성능이 대폭 뛰었습니다.

또한 에이전트 RL 생태계를 위해 코딩 3k, 보안 1k, 지식 업무 1k, 웹 개발 2k 등 총 7,000개 이상의 실행 환경 및 검증기가 포함된 데이터셋(MiMo-V2.6-RL-oss)과 9B 증류 모델도 오픈소스로 공개했습니다.

마치며:

LLM의 성능은 데이터와 강화학습이 지배한다고 자주 이야기를 했지만, MiMo-V2.6으로 이를 증명할 실제 사례가 생긴 것 같습니다.

강화학습에서 필수적으로 필요한 것은, 멀티턴 환경에서 중간 단계를 채점하는 방법과 강화학습에 적합한 옵티마이저 그리고 학습을 진행할 하네스 같네요. 각각 연구할 가치가 있고, 앞으로가 기대되는 분야입니다.

샤오미는 모델을 MIT 라이선스로 공개한 것뿐만이 아닌, 학습 데이터에 RL 과정까지 공개하면서 엄청난 개방성을 보여줬습니다. 참 대단하고 고맙네요. 앞으로도 학습 과정을 공개해주는 모델들이 많이 나오길 기대합니다.
