title: "OpenRouter 1위 무료 모델 Ox Alpha의 등장과 실전 에이전트 사용기"
---

비공식 DeepSWE subset에서 Ox Alpha(80%)가 Fable-5(65%)와 GPT-5.6-Sol(52%)을 압도하는 성능을 낸다면서 큰 화제를 모으고 있습니다. Ox Alpha는 8월 21일 OpenRouter에 무료로 공개된 모델로, 아직은 누가 만들었는지 모릅니다. 참고로 1주일간 무료라고 하니 Claude Code 같은 코딩 에이전트에 연결해서 많이 써 보시는 것을 추천드립니다.

Ox Alpha는 무료이면서 뛰어난 성능을 바탕으로 벌써 OpenRouter에서 가장 인기가 있는 모델로, 사람들이 하루에 4T token 이상을 사용하고 있습니다. 저도 Codex와 Claude Code에 연결해서 사용해 봤습니다.

GPT-5.6나 Fable-5를 썼을 때와 성능 차이는 느끼지 못했습니다. 다만 GLM-5.2를 썼을 때처럼, 중국 모델 특유의 답답한 과추론이 느껴지고 무료라 그런지 모르겠으나 무겁고 느린 느낌을 받았습니다. 

그리고 가끔씩 API 연결이 끊어집니다. Codex보다는 Claude Code에 연결해서 쓰는 것이 낫습니다. Ox Alpha와 Claude Code의 궁합이 더 좋은 것 같고, 잠깐 API 연결이 끊겨도 다시 자동 연결을 해줍니다. Codex는 연결이 끊기는 순간 작업이 멈춥니다.

연결하는 방법은 구글 AI 모드에 질문해도 쉽게 알려줄 테니 한 번 해 보시는 것을 추천드립니다. 추후에는 공식 버전을 사용해보고 싶네요.

매니폴드 마켓에서는 Ox Alpha의 제작사가 80% 이상의 확률로 GLM 시리즈를 만든 Z.ai일 것이라고 예측하고 있습니다. 저도 그 가능성이 가장 높다고 생각하고, 개인적으로 그 다음으로는 최근 10T 모델을 만들고 있다고 발표한 바이트댄스나, 2.7T 급의 모델을 만들고 있다는 MiniMax도 가능성이 높지 않을까 싶습니다.

요즘은 대단한 모델들이 계속 나오고 있습니다. 만약 이게 정말 중국 모델이고, 공식적인 성능에서도 최고 성능을 달성한다면, 큰 사건이 될 것 같네요.
