---

인공지능 발전의 속도를 조절해야 된다고 하던 앤트로픽, OpenAI, SpaceXAI가 일제히 새로운 모델을 공개했습니다. 인류의 존재 위험 같은 발언에 대한 책임감은 보이지 않네요.

그와 별개로 정말 뛰어난 성능의 모델들을 보여줬습니다. 속도 경쟁은 더욱 심화되고, 그들이 말하는 위험이 사실이라면 이를 가속화 시키고 있습니다.

거기다 최근 RL 로그를 실시간 공개해서 화제를 모았던 샤오미의 MiMo-V2.6-Pro도 공개됐습니다. 이번 모델로 오픈웨이트 모델 중에서는 AAII 최고 점수를 차지하게 됐습니다.

Claude Opus 5.5는 AAII에서 Fable 5.1과 GPT-6 Astra 보다 5점 높은 58점을 기록하며, 모든 모델들 중 압도적인 선두를 차지하고 있습니다.

거기다 GPT-5.6 Sol과 같은 가격으로 1M당 입력 $4, 출력 $20입니다. 기존 Opus 5 보다도 20% 싼 가격이죠. 다만 추론량이 엄청나서 싸다는 느낌이 들지는 않을 것 같습니다.

GPT-6 Sol은 GPT-5.6 Sol의 반값의 가격으로 1M당 입력 $2, 출력 $10입니다. 거기다 더 빠른 속도와, 훨씬 더 적은 추론으로도 높은 성능을 자랑합니다.

OpenAI는 GPT-6 Astra 이후 CoT 토큰 수를 조절하는 방법을 배운 것 같습니다. 루프 모델이 빛을 발하는 지점입니다. 참고로 AAII를 풀기 위해 Claude Opus 5.5는 260M 토큰을 사용했고 GPT-6 Sol은 77M 토큰을 사용했습니다.

Grok 4.7은 1M당 입력 $2, 출력 $6로 비교적 가성비 모델로 보이지만, AAII를 풀기 위해 240M 토큰을 사용해 GPT-6 Sol의 3배 이상을 사용했으며, 오히려 작업 비용은 GPT-6 Sol 보다 훨씬 더 비쌉니다.

MiMo-V2.6-Pro는 정말 잘 만든 모델 같습니다. 단순한 GQA + SWA 구조로 오픈웨이트 모델 중 최고 성능을 달성했습니다. 오직 데이터와 RL의 승리로 보입니다.

GRPO를 쓸 때 단순 정답 판별을 넘어 실행 과정 전체를 채점하는 Groupwise Agentic Grader와 멀티 하네스 기반의 대규모 RL 레시피로 만들어낸 결과입니다. 이 내용은 추후 다른 글에서 자세히 다뤄보겠습니다.

MiMo-V2.6-Pro는 1.02T A42B 모델이고, 1M 컨텍스트를 지원합니다. 이미지, 비디오, 오디오까지 지원하는 멀티모달 모델이며, MIT 라이선스로 공개됐습니다! API 가격도 1M당 입력 $0.435, 출력 $0.87라는 말도 안 되게 싼 가격을 자랑합니다.

이런 결과를 보니, OpenAI와 앤트로픽의 모델들의 구조가 궁금해집니다. 저들도 생각보다 단순하지 않을까 싶네요. 동시에 저들의 데이터와 RL 방식이 더욱 궁금해집니다.

미국은 인공지능의 발전이 위험하니 속도 조절을 해야 한다고 말하자마자 새로운 독점 모델들을 공개했습니다. 중국은 새로운 프론티어 모델을 MIT 라이선스로 공개하고, 자세한 테크니컬 레포트, 학습 레시피 뿐만 아니라 RL 로그를 실시간 공개했습니다.

우위에 서기 위해 자극적인 키워드로 선동을 하고 폐쇄를 택한 권위적인 미국과, 기술과 노하우를 개방하고 민주적인 중국이라니... 정말 신기한 시대입니다.
