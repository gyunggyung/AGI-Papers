---

중국 모델이 실제 코딩 작업에서 프론티어 모델 수준의 실용성을 보여준 기점은 GLM-5.2부터였습니다. Claude나 GPT를 대체할 수준으로 평가받는 비결은 멀티턴 중간 과정까지 피드백을 주는 "Single-Rollout Asynchronous Optimization(SAO)"에 있습니다.

멀티턴 환경에 적합하지 않은 기본적인 GRPO를 포기하고 PPO를 개선해 GLM-5.2, GLM-5.3 계열을 완성한 "Single-Rollout Asynchronous Optimization for Agentic Reinforcement Learning" 논문의 핵심을 정리합니다.

1. 멀티턴 에이전트: "내 행동"과 "환경 출력"의 혼재

코딩 에이전트는 검색, 코드 열람, 패치 실행 등 수십 턴의 대화가 이어집니다.

- 1턴: [유저 요청] -> (모델: 파일 검색 명령어 입력)
- 2턴: [터미널: 검색된 코드 목록 출력] -> (모델: 200줄 코드 열람)
- 3턴: [터미널: 코드 내용 출력] -> (모델: 수정 코드 작성 및 실행)
- 4턴: [터미널: 테스트 통과 or 에러 로그] -> (모델: 최종 종료)

핵심은 내가 쓴 코드(Action) 사이에 시스템 터미널이 뱉은 출력(Observation)이 교차로 섞인다는 점입니다.

2. GRPO가 멀티턴에서 무너지는 이유

GRPO는 기본적으로 한 문제당 8개 이상의 궤적을 뽑아 최종 결과(1점 or 0점)로만 그룹 비교를 합니다.

- 피드백 뭉개짐: 30턴 중 28턴을 완벽히 수행해도, 29턴의 사소한 오타로 실패하면 앞선 훌륭한 도구 호출까지 전부 감점 처리됩니다. 그렇게 올바른 학습 기회들도 놓치게 됩니다.
- 대기 병목(Straggler): 샘플마다 턴 길이가 달라 느린 궤적을 기다리는 사이 모델이 먼저 업데이트되어, 옛날 버전의 행동을 가지고 억지로 학습하다가 스텝이 꼬여버립니다. 결국 비동기 환경의 GRPO는 160스텝 만에 성능이 붕괴합니다.

3. SAO의 핵심: 가치평가 모델(Critic) 구축

SAO는 중간 과정을 정밀 채점하는 가치 평가 모델을 도입합니다.

- 구조: 베이스 모델(Qwen3-30B-A3B)에 성공 확률(Scalar)을 출력하는 Value Head를 붙입니다. 여기에서 0 ~ 1.0 사이 성공 확률 점수를 구합니다.
- 사전 훈련(Pretraining): 엉터리 채점으로 인한 붕괴를 막고자, GPT-OSS-120B가 생성한 도구 추론(TIR) 데이터로 3 에포크 사전 학습을 거칩니다.
- 안정화: 학습 중 Attention은 동결(Freeze)하고 MoE 레이어만 업데이트해 메모리를 아끼고 발산을 막습니다. 정책보다 가치 모델을 2배 빠르게 갱신(K=2)해 빠른 변화를 놓치지 않습니다.

4. 멀티턴 중간 경로를 정밀 타격하는 Skip-Observation Token GAE

- 환경 노이즈 차단: 모델이 쓰지 않은 터미널 출력 구간은 건너뛰고, 이전 행동 끝 토큰과 다음 행동 첫 토큰의 가치만 직접 연결해 오차를 구합니다.
- 토큰 단위 핀포인트 감점: 28턴까지 성공 확률 90%를 유지하다 29턴 실수로 10%로 꺾였다면, 1~28턴은 살리고 29턴의 실수 토큰만 정확히 강하게 감점합니다. 턴 단위로 뭉뚱그려 평가하는 것보다 토큰 단위로 세밀하게 연결하는 것이 논리적 전환을 훨씬 잘 잡아냅니다.

5. 숫자로 증명된 멀티턴 성능

프롬프트당 딱 1개(Single-Rollout)만 뽑아 즉시 비동기 학습에 투입합니다. 정밀한 학습으로 GRPO를 압도하는 결과를 냅니다.

- SWE-Bench Verified (최대 300턴 코딩): 베이스라인 23.0% -> GRPO(+DIS) 27.0% -> SAO 29.8%
- AIME 2025 (도구 추론): 베이스라인 80.4% -> GRPO 84.2% -> SAO 97.3%
- BeyondAIME: 베이스라인 53.3% -> GRPO 54.8% -> SAO 74.8%

마치며:

실제 GLM-5.2의 가치 평가 모델을 만들 때의 사전 훈련 데이터는 어떻게 넣었을지 궁금하네요. 아마도 이때 GPT나 Claude 최신 모델을 증류하지 않았을까 예상해봅니다.

아무튼, 멀티턴이 필수인 에이전틱 환경에서 단순히 최종 결과만을 가지고 평가를 하는 방식에는 한계가 있습니다. 이를 PPO 스타일로 풀어낸 SAO는 매우 흥미롭고, 중국 프론티어 모델의 강화학습 비결을 알려준 기념비적인 논문입니다.

이제 GRPO로 학습할 때도 중간 단계마다 평가를 하는 방식이 필수가 되고 있습니다. 다음에는 GRPO로 이 문제를 해결하며, 오픈 웨이트 모델 중 최고 성능을 달성한 MiMo-V2.6 테크니컬 리포트 내용을 소개해 드리겠습니다.
